# Un pequeño universo para Jenifer

Recorrido completo del regalo de cumpleaños para Jenifer Balcon, 10 de noviembre de 2026.

## Abrir con Live Server

1. Abre esta carpeta en Visual Studio Code.
2. Abre `index.html`.
3. Usa **Open with Live Server** desde el menú contextual o el botón **Go Live**.
4. El sitio se abrirá en el navegador, normalmente en `http://127.0.0.1:5500`.

No necesita instalación ni proceso de compilación.

## Incluido hasta esta etapa

- Bienvenida animada con estética celestial.
- Seis estrellas interactivas con mensajes.
- Progreso guardado localmente en el navegador.
- Estrella fugaz activada una sola vez al llegar a 3/6.
- Migración automática del progreso guardado durante la primera etapa.
- Séptima estrella revelada al completar la constelación.
- Carta final desbloqueable y disponible para volver a leer.
- Sonidos generados en el navegador para estrellas, estrella fugaz, constelación, séptima estrella y carta.
- Control para activar o silenciar sonidos; la preferencia queda guardada.
- Navegación por teclado, estados anunciados y soporte para `prefers-reduced-motion`.
- No hay autoplay ni archivos de audio externos.
- Líneas de constelación que se iluminan con el progreso.
- Destellos de descubrimiento, profundidad reactiva del cielo y revelaciones al desplazarse.
- Apertura animada de la carta con alternativa sin movimiento.
- Capas de estrellas en movimiento continuo y estrellas fugaces ambientales aleatorias.
- Recorridos lentos y ligeramente curvos para poder apreciar las estrellas fugaces.
- Constelación orgánica con curvas luminosas conectadas a la posición real de cada estrella.
- Transición luminosa entre cada estrella y su tarjeta, ondas por la constelación y audio posicional.
- Fotografías cinematográficas con marcos orbitales, nodos estelares, encuadre individual, color ambiental y parallax sutil.
- Ondas luminosas escalonadas y revelación final reforzada para mayor presencia visual.
- Fotografías asignadas a las estrellas 1, 3 y 6, más una composición protagonista con doble órbita y aureola para la fotografía de la carta.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: sistema visual, responsive y animaciones.
- `script.js`: interacción, diálogos y progreso local.

## Música opcional

La música de piano puede añadirse después, únicamente con un archivo proporcionado y autorizado. Los efectos actuales se sintetizan con Web Audio API y funcionan sin conexión.
